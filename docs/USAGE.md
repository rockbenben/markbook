# 使用指南 Usage

启动后浏览器自动打开。左侧是目录(TOC),右侧是连续阅读区,顶部是工具栏,底部状态栏显示章数 / 字数 / 预计阅读时长 / 当前章 / 阅读进度。

## 选择要读的库

- 启动时用参数或 `CV_ROOT` 指定(见 [CONFIGURATION](CONFIGURATION.md)),或
- 在工具栏「**设置**」里改:手填路径,或用目录浏览树点选**文件夹**或**单个文件**(`.md`/`.txt`);可同时设排序方式、标题来源。应用后整库即时切换,并被记住(存在本浏览器)。
- **最近书库**:设置面板会列出最近打开过的库,点一下即填入根目录,再「应用」即可快速切回(在多本书之间来回时尤其省事)。
- **网页版(静态部署)**:见 [DEPLOY](DEPLOY.md)。首屏直接点「打开文件夹 / 打开单个文件」选你自己的 `.md` / `.txt`(或「先看看示例」),全程在你浏览器本地,不上传。

## 阅读

- **连续视图**:所有章节拼成一页滚动文档,虚拟化渲染,几百上千章也流畅。
- **排版 / 原文**:工具栏的分段开关切换全局视图。「排版」下 `.md` 按 GFM 渲染、`.txt` 按正文段落排版(自适应:有空行按空行分段并合并折行,无空行一行一段;与正文同样的字体 / 行距 / 缩进);「原文」下都看等宽原样源文。`.md` 支持顶部 YAML frontmatter——其中 `title` 用作章节标题,整块在阅读时隐藏。图片等比缩放,不会溢出阅读栏。
- **目录(TOC)**:按卷分组、可折叠(自动展开当前卷),顶部有过滤框输入章名快速定位;滚动时高亮当前章并自动滚动跟随;点条目平滑跳转。
- **翻章**:工具栏「上一章 / 下一章」按钮,或快捷键 `j` / `k`、空格 / `Shift+空格` 翻页、`Home` / `End` 到首 / 末章。
- **位置记忆**:重开或刷新自动回到上次读到的章节。
- **超大单章**:某章正文极长(如几十 MB 文件被当成一整章)时,排版视图自动**分页**(底部「上一页 / 下一页」),任一时刻只渲染一页,不卡顿。

## 阅读设置(工具栏 Aa)

- **字号**、**行距**、**字体**(系统 / 衬线 / 等宽)、**页宽**(窄 / 中 / 宽 / 全宽)。
- **首行缩进**(中文小说排版,可关)。
- **背景**:默认 / 护眼(米黄)/ 羊皮纸 / 夜间——作用于**整个界面**(工具栏、目录、内容、弹层都跟随),像换纸张。
- 全部即时生效并持久化(按设备记忆)。
- 工具栏另有明暗主题切换。**仅当背景为「默认」时**该开关可用、可手动切明 / 暗;选了护眼 / 羊皮纸 / 夜间背景时,明暗由背景本身决定,主题开关被禁用(悬停提示「明暗由阅读背景决定，选择『默认』背景可手动切换」)。

## 沉浸 / 进度 / 书签

- **沉浸模式**:工具栏全屏按钮,隐藏目录与工具栏只留正文;`Esc` 或右上角按钮退出。
- **进度**:状态栏显示总体百分比与进度条,以及当前卷内位置。
- **预计阅读时长**:按全书字数(约 400 字 / 分钟)估算,显示在状态栏字数之后。
- **书签**:工具栏星标按钮为当前章加 / 取消书签;书签列表按钮打开列表,点条目跳转,× 移除。书签存在本地。

## 搜索(工具栏搜索框)

- 全文检索,中文分词,多词、前缀匹配、按相关度排序。
- 下拉每条显示「标题 · N 处 · 行号 · 片段」;选中跳到该章。命中很多时只展示前若干条。
- 选中结果跳转后,会在该章内**高亮查询词**并滚动到首个命中,便于一眼定位(浏览器支持 CSS Highlight API 时生效)。无命中时下拉显示「无匹配结果」。

## 编辑

- 点右下角**编辑**按钮编辑**当前所在章**(或在目录里对某章操作);编辑器是覆盖阅读栏的抽屉(不挡目录 / 工具栏)。
- **CodeMirror**:Markdown 语法高亮;`Ctrl/Cmd+F` 打开**查找替换**面板。
- **双栏 / 单栏**:抽屉内切换,双栏时右侧实时预览。
- **保存**:`Ctrl/Cmd+S` 或「保存」按钮写回源文件;可开「**自动保存**」(停手约 1.5s 自动存);**关闭前若有未保存改动会提示**。
- **冲突保护**:基于文件 mtime,若文件被外部改动而你也改了,会提示「查看磁盘版本 / 强制覆盖」,**不静默覆盖**。
- 单文件模式下,编辑某节只精准写回文件对应区间,其它节不受影响。

## 全局查找替换(工具栏)

跨**所有章节**查找替换:输入查找 / 替换词(可选正则),先「**预览**」看哪些章命中、各几处,确认后「**全部替换**」写回。目录模式逐文件、单文件模式整文件处理。

## 章节管理(目录里每章的 ⋯ 菜单 / 新建按钮)

- **新建**:目录模式新建一个 `.md` 文件(`# 标题`);单文件模式在末尾追加一节。
- **重命名**:改章节**标题**——有标题行则改标题行(文件名 / 顺序不变),无标题(按文件名)则重命名文件;单文件模式改该节标题行。
- **删除**:目录模式删文件,单文件模式删该节;均需确认。

## 导出(工具栏)

整本或**按卷**导出为:

- **TXT** —— 导出为纯文本,每章以其标题起始;先剥离 frontmatter,再去掉与标题重复的首行(含 `.txt` 章节标题后的 Setext `===` 下划线)。`.txt` 章节正文**按字面导出**(与阅读一致,不动任何标记);`.md` 章节**移除部分** Markdown 标记:标题 `#`、粗体 / 斜体(`**`、`*`、`__`、`_`)、行内代码反引号、引用 `>`(链接 / 图片、列表符号、表格、代码围栏等仍原样保留)。有卷时按卷分组,卷名作分隔。
- **Markdown** —— 合并各章原文(保留 Markdown),剥离每章 frontmatter;有书名时输出一级标题,有卷时插入 `# 卷名` 分组。
- **HTML** —— 单文件、自带目录与样式,可离线阅读 / 分享。
- **EPUB** —— 放进 Kindle / 手机阅读器(**仅服务端版**;网页版未提供,可改用 HTML / PDF)。
- **PDF** —— 打开排版好的 HTML 调用浏览器打印(选「另存为 PDF」)。

## 实时同步

用别的编辑器改了源文件、新增或删除文件,MarkBook 会通过 WebSocket 自动更新视图,无需手动刷新,并尽量保留滚动位置。工具栏也有「刷新」做手动全量重载兜底。
