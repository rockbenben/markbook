# 配置 Configuration

**服务端不再持久化配置**:`root` / 排序 / 标题来源等设置由**各自的浏览器**(localStorage)记住,连上服务端后自动下发。这样同一个服务端被多人共用时,各人的设置互不覆盖——不存在一份共享的服务端配置文件。服务端启动时只用一个**引导默认 root**(命令行 / `CV_ROOT` / 已存在的旧 `~/.chapter-viewer/config.json`,若有),且**只读不写**。

> 注意:服务端同一时刻只服务**一个**活动根目录(单一章节索引 + 文件监听)。多人同时用不同文件夹请改用[静态部署](DEPLOY.md)版(各自浏览器、各自的文件)。

## 根目录从哪来(优先级)

1. **浏览器记住的 `root`**:你在界面「设置」里选过文件夹后,本浏览器会记住并在连上时下发——刷新 / 服务端重启后自动重新打开。
2. **命令行参数** `node dist/server/index.js <路径>` 或 **`CV_ROOT`** 环境变量——作为服务端的引导默认值(浏览器尚无记忆时使用)。
3. 旧的 `~/.chapter-viewer/config.json`(若存在)里的 `root` 作引导默认。
4. 都没有则回退到**当前工作目录**。

根目录可以是一个**目录**,也可以是一个**单文件**(`.md` / `.txt`),见 [FORMATS](FORMATS.md)。在界面「设置」里既能手填路径,也能用目录浏览树(可选文件夹或文件)。

## 设置存在哪

界面「设置」里的改动(根目录、排序、标题来源、最近书库)**保存在你的浏览器 localStorage**,即时生效、按设备记忆;服务端不写任何配置文件。下次打开 / 服务端重启后,由本浏览器把记住的设置重新下发。

可选的引导文件 `~/.chapter-viewer/config.json`(若手动放置)在启动时**只读**,用于给出默认 `root` / `ignore` / `sortMode` / `titleSource`:

| 字段 | 默认 | 说明 |
|---|---|---|
| `root` | (启动时推断) | 引导默认的目录或文件 |
| `ignore` | `["**/.*", "**/node_modules/**", "**/.git/**"]` | glob 忽略规则(picomatch 语法) |
| `sortMode` | `"path"` | `path`(目录→文件名→标题)/ `global`(全局按标题)/ `volume`(子目录当卷,先卷后章);均为中文数字感知的自然排序 |
| `titleSource` | `"heading"` | `heading`(首个标题优先,回退文件名)/ `filename`(强制用文件名) |

(注:`ignore` 目前只能通过该引导文件设置;`root` / 排序 / 标题来源平时在界面里改即可,自动存浏览器。)

## 环境变量

| 变量 | 说明 |
|---|---|
| `CV_ROOT` | 引导默认的根目录 / 文件(优先级低于命令行参数) |
| `CV_PORT` | 后端端口,默认 `5179`(开发时前端 5173 经代理转发到它) |
| `CV_NO_OPEN` | 设为任意值则启动不自动打开浏览器 |
| `CV_HOST` | 监听地址,默认 `127.0.0.1`(仅本机)。对外提供请设 `0.0.0.0`,并务必配合 `CV_TOKEN` |
| `CV_TOKEN` | 设置后,`/api` 与 `/ws` 需带此令牌(请求头 `x-cv-token` 或 `Authorization: Bearer`,WS 用 `?token=`)。前端会从 URL `?token=` 读取并存 sessionStorage;也可在弹窗里粘贴 |
| `CV_BASE` | 设置后,目录浏览与可选根目录被**沙箱**限制在此目录内,防止访问服务器其它位置 |

PowerShell 设环境变量:`$env:CV_ROOT='D:\我的小说'; npm start`。

> **对外部署安全**:默认只听本机,安全。一旦设 `CV_HOST=0.0.0.0` 对外,**强烈建议**同时设 `CV_TOKEN`(鉴权)与 `CV_BASE`(限制可访问目录);否则任何人都能浏览并读写服务器文件。未设 token 却对外暴露时,启动会打印安全警告。生产中也可改用反向代理(nginx/Caddy)做鉴权。

## 忽略规则 `ignore`

glob,匹配相对根目录的路径。默认排除隐藏文件、`node_modules`、`.git`。可加自己的规则,例如 `"**/*.draft.md"`、`"**/归档/**"`。注意要排除某个目录本身,通常同时给 `"**/名字"` 与 `"**/名字/**"`。

## 排序 `sortMode`

- **`path`(默认)**:按目录路径 → 文件名 → 标题逐级自然比较。最适合 `第001章.md` 这类靠文件名定序、分卷放在子目录里的库。
- **`volume`**:顶层子目录当卷,先按卷再按标题。
- **`global`**:忽略目录结构,全局按标题排。

中文数字会被正确排序(`第二章` 在 `第十章` 前)。详见 [FORMATS · 排序](FORMATS.md#排序)。

## 都存在浏览器 localStorage(按设备记忆)

服务端版与静态版**所有设置都存在本机浏览器**,不上传、不写共享配置文件:
- 主题明暗、阅读设置(字号 / 行距 / 字体 / 页宽 / 首行缩进 / 背景)、沉浸模式、编辑器双栏 / 自动保存开关
- 书签、各本书的上次阅读位置
- 根目录、章节顺序、标题来源、最近书库(服务端版连上后下发给服务端)

静态版另把所选目录 / 文件句柄存在 **IndexedDB**(供「最近打开」一键切换)。换浏览器 / 换设备 / 清除浏览数据会各自独立或清空,属正常。
