# 支持的格式与解析规则

MarkBook 处理两种文件类型,两种组织方式;章节的来源、标题、顺序都按下面的规则确定。它适应**各类文本**——小说、文档、笔记、报告——而不仅是某一种。

## 文件类型

- `.md` —— 按 GFM 渲染(标题、列表、表格、代码块、链接、图片、引用)。支持顶部 YAML frontmatter(见下)。
- `.txt` —— 纯文本。**排版**视图按段落渲染(与 md 同样的阅读字体/行距/缩进):有空行分隔时按空行分段、段内折行合并(CJK 无空格、西文加空格),无空行时一行一段;**原文**视图等宽原样展示。

图片(md)等比缩放到阅读栏宽度内,不会溢出。

**超大单章**:某一章正文极长(如几十 MB 无标题文件被当成一整章)时,排版视图会**分页**显示(底部「上一页 / 下一页」),任一时刻只把一页放进 DOM,避免卡顿。

其它扩展名忽略。默认忽略隐藏文件、`node_modules`、`.git`(可在配置 `ignore` 用 glob 调整)。

## 两种组织方式

### 1. 目录模式(根目录是一个文件夹)

- 递归扫描所有子目录的 `.md` / `.txt`,**每个文件 = 一章**。
- 顶层子目录名作为**卷**(volume),用于 TOC 分组。
- 章节**标题**:优先取 md frontmatter 的 `title`;否则取文件中第一个标题行(`# …`);再否则回退为文件名(去扩展名)。可在配置把 `titleSource` 设为 `filename` 强制用文件名(此时 frontmatter 也忽略)。
- **frontmatter**(md):文件顶部 `---` 起、到下一行 `---` 止的 YAML 块。其中 `title` 用作章节标题;整块在阅读时**隐藏**,不当作正文显示(原文视图仍可见)。
- 顺序:见下方[排序](#排序)。

### 2. 单文件模式(根目录是一个文件)

打开**一个** `.md` / `.txt` 时,MarkBook 按文件内的**标题**把它切成章节(小节)。每节从它的标题行到下一个同级标题前,小节正文**包含**自己的标题行;首个标题之前的非空文字成为「前言」小节。识别出层级时,较浅的标题作**卷**、较深的作**章**(规则:出现 ≥2 个的最深层级为「章」,更浅的为「卷」)。编辑某节会精准写回文件对应区间。

## 识别的标题格式(单文件模式)

> Markdown 文件若含 `#` 标题,只按 `#` 切分。`.txt`(以及**没有任何 `#` 的** `.md`)走下面的通用识别。

**Markdown**
- `#` ~ `######` 标题,`#` 数 = 层级(`#`=卷、`##`=章 等)。
- Setext 下划线:某行下面紧跟一行 `===`(≥3,记为一级)或 `---`(≥3,记为二级)。

**中文章节 / 卷**(数字支持阿拉伯、全角、中文数字)
- 章:`第<数>[章节回话折幕]`,如 `第一章`、`第12章`、`第１０回`、`第三幕`;以及 `正文 第X章`。
- 卷:`第<数>[卷部篇集]`、`卷<数>`、`上/中/下 卷 / 部 / 册`。
- 特殊单章(无编号):`序` / `序章` / `序言` / `楔子` / `引子` / `前言` / `卷首语` / `扉页` / `尾声` / `终章` / `后记` / `番外` / `外传` / `附录` / `完本感言`。

> **`.txt` 里的 `#` 与 Setext 是装饰**:行首的 `#`(markdown ATX 前缀)在 `.txt` 中被**忽略**——`# 第一篇` 等同于 `第一篇`,层级由上面的中文/编号语义决定。当一行同时是中文语义标记又带 Setext 下划线(如 `第一章\n=====`)时,**以语义为准**(`第一章` 判为章级),下划线只作装饰。这样混用 `# 第N篇`(卷)+ `第X章\n===`(章)的小说也能正确分出卷 / 章层级。
> 注意:`# 最终篇` 这类**非 `第<数>篇`** 的卷名因无中文数字语义,不会被识别为卷,其章节并入上一卷。

**编号小节**(通用文档)
- 中文编号:`一、引言`、`（一）背景`、`(1) …`。
- 阿拉伯编号:`1、标题`、`1. 标题`、`1) 标题`;小数层级 `1`、`1.1`、`2.3`(层级 = **点分段数**,即按 `.` 切开的段数)。

  | 编号 | 段数 | 层级 |
  |---|---|---|
  | `1` | 1 | 1 |
  | `1.1` / `2.3` | 2 | 2 |
  | `1.1.1` | 3 | 3 |

  （注意是「段数」而非「点数」:`1` 没有点但是第 1 级,`1.1` 一个点是第 2 级。）

**英文**
- `Chapter N`、`Ch. N`、`Section N`、`Volume / Vol N`、`Book N`、`Part N`。

标题行可带 `【】「」『』《》〈〉[]（）` 等包裹与首尾空白。

### 防误判(很重要)

为了不把普通正文 / 散文里的句子误当标题,编号 / 特殊 / 中文枚举类标题必须是**独立的短行**:整行就是标题(+可选短标题),长度 ≤ 40 字,且不含句中标点 `。！？；…，,`(结尾冒号允许)。所以像「第二天,他去了公司。」「第三方接口设计说明」「1. 这是一个很长的句子,并不是标题。」都**不会**被当成标题。`第<数>章` 这类带强标记的也受此约束。Setext 因为有下划线本身就足够明确。

此外,标记后接负向断言排除常见词:`回合 / 回访 / 回忆…`(回)、`节课`(节)、`部分 / 部赛 / 部游`(部)、`集合 / 集和`(集)、`篇张`(篇)、`幕布 / 幕前 / 幕后`(幕)——故「第三回合」「第二部分」「第三节课」等不会被误判为章 / 卷。

> 阅读时(`.txt` 排版视图),整行纯符号的**分隔条**(`====`、`----`、`****`、`~~~~` 等,≥3 个符号)被视为装饰,不作为正文段落显示;但纯句子标点行(`……`、`。。。`)保留。

> 没有任何可识别标题的文件 → 整篇作为一节(标题取文件名),依然可读、可搜、可整体编辑。

## 排序

`sortMode`(配置项)决定章节顺序;所有比较都用**自然排序**,理解阿拉伯、全角和**中文数字**:

- `path`(**默认**,目录优先):先按目录路径,再按文件名,最后按标题。每段都自然比较。
- `volume`:先按卷(顶层子目录)再按标题。
- `global`:全局按标题。
- `manual`(**手动**):目录模式专用,在 TOC 中拖动章节自定义卷内顺序;顺序存浏览器 `localStorage`(`cv-order:<root>`),不写入文件。

**中文数字自然排序**:`第二章` < `第十章` < `第十二章`(而非按字符码),`卷二` < `卷十`,全角 `第２章` < `第１０章`,阿拉伯 `chapter-2` < `chapter-10`。单文件模式按文件内出现顺序,无需排序。

`parseChineseNumber` 支持 `零〇一..九 / 壹..玖 / 十百千万 / 两 / 廿卅卌`,如 `二十三`=23、`一百零八`=108、`两千零五`=2005。

## 字数统计

CJK 按字符计、拉丁/数字按词计,两者相加(含星平面表意文字 `\p{Script=Han}` 与假名);显示在状态栏(总字数 + 单章字数)。
